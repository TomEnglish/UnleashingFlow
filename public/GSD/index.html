The Decision

Three paths. One north-star spec.

We evaluated off-the-shelf stacks, a hybrid approach, and a fully custom build. The full technical spec describes where you could land in 2–3 years. You don't have to fund all of it on day one.

Path A — Buy & Wire

iCans Plus + Zapier + off-the-shelf AI add-ons. Lowest build cost, highest long-term SaaS drag if you grow.

Recommended

Path B — Hybrid

Custom AI layer (inbox, voice, owner's-voice email) + proven dispatch software for routes, driver app, and QB sync.

Path C — Full Custom

Everything in the technical spec — full ownership, highest build effort. Matches the 20-week blueprint.

Path B — Recommended

Hybrid — custom AI where you differentiate

Custom layer (we build)

  • Unified conversation inbox (email, SMS, voice transcripts)
  • AI reply suggestions with owner's-voice Gmail drafts
  • Knowledge base + RAG for accurate answers
  • Lead scoring, follow-up sequences, campaign engine
  • After-hours voice agent (VAPI) — v1.1
  • Analytics & KPI dashboard

Keep on proven SaaS

  • iCans Plus — dispatch board, driver app, route optimization
  • QuickBooks — invoicing & payments (sync via iCans)
  • Option to migrate off iCans in Year 4–5 if needed
Why hybrid wins: Generic SaaS-bundled AI is mediocre for voice agents and email-in-your-voice. You get the AI differentiator without rebuilding dispatch — the part that's hard and not where customers feel the magic.

~70 hours total · ~$10,500 · v1 pilot (Phases 1–3) ≈ 40–50 hrs / $6K–$7.5K

Path C

Full custom — the complete blueprint

Everything in the technical spec: custom dispatch board, driver hub, QuickBooks integration, booking flow, reviews, multi-market webhooks. Built on Next.js + Supabase + OpenRouter.

Next.js 14 ──► Supabase (Postgres + Auth + Realtime) │ ├── OpenRouter (all LLM tasks) ├── VAPI (voice) ├── Twilio + SendGrid (messaging) ├── QuickBooks + Stripe (money) └── 25+ database tables · 25+ API routes

~135 hours · ~$20,250 · Best TCO at 30%+ CAGR over 5 years · Highest execution risk today
