Technical Specification

Version 1.0 — full custom blueprint (Path C). Stack: Next.js 14 + Tailwind + Supabase + OpenRouter. This describes the north-star system; the recommended pilot (Path B) implements Phases 1–3 first.

25 database tables · 25+ API routes · 16 feature modules · 10 build phases over 20 weeks
1. Business Context & Vision
  • 10-yard & 20-yard roll-off rentals — Houston & Katy, TX
  • Ideal clients: residential contractors, commercial GCs, disaster restoration, realtors
  • Current tools: Gmail, QuickBooks, dispatch software, Google Sheets
  • 10-year goal: $10M business valuation
  • Six KPIs: hours saved, lead response time, conversion rate, DSO, review velocity, monthly revenue
2. Core Features (16 modules)
  • 2.1 Lead acquisition — CSV, Apollo, Clay, permits, webhooks, duplicate detection, scoring 0–100
  • 2.2 AI outreach — Per-segment prompts, owner's-voice, A/B variants, email/SMS/LinkedIn
  • 2.3 Voice agent — VAPI/Bland, 24/7 qualification & booking, transcripts
  • 2.4 Owner's-voice email — Gmail OAuth drafts, trained on 20–50 past emails
  • 2.5 Reply handler — Multi-channel inbound, RAG, confidence scoring, escalation
  • 2.6 Follow-up scheduler — Per-segment cadence, pause logic, re-engagement
  • 2.7 Quotes & booking — Dynamic pricing, PDF, e-sign, Stripe, ETA notifications
  • 2.8 QuickBooks — OAuth, auto-invoice, customer sync, AI dunning, DSO
  • 2.9 Driver hub — Mobile view, AM dispatch SMS, inbound status parsing
  • 2.10 Knowledge base — Markdown editor, pgvector RAG, test playground
  • 2.11 Conversation inbox — Unified threads, AI suggestions, sentiment colors
  • 2.12 Pipeline & dispatch — Kanban, calendar, driver assignment, SLA alerts
  • 2.13 Google reviews — Post-job SMS sentiment → review link or private feedback
  • 2.14 Accounts — Repeat customers, LTV, tiered contractor pricing
  • 2.15 AI model management — OpenRouter, per-task models, cost caps, fallbacks
  • 2.16 Analytics — Today dashboard, funnel, AI cost per booked job, weekly reports
3. Architecture

Frontend: Next.js 14 App Router, Tailwind, shadcn/ui, TanStack Query, Recharts — deployed on Vercel.

Backend: Supabase Postgres 15, Auth, Storage, Edge Functions, pg_cron, pgvector, RLS on every table.

Integrations: OpenRouter, VAPI, Twilio, SendGrid, Gmail OAuth, QuickBooks, Stripe, Apollo/Clay, Google Business Profile.

Jobs: Supabase Edge Functions + pg_cron; Inngest/Trigger.dev for complex retry chains.

Observability: Sentry, PostHog, OpenRouter dashboard.

4. Database Schema (25 tables)
  • organizations, org_members — multi-tenant, roles (owner, admin, sales, dispatcher, driver, readonly)
  • accounts — repeat customers, LTV, pricing tiers, QB customer ID
  • leads — full contact, enrichment, engagement, compliance fields
  • tags, lead_tags
  • conversations, messages — AI metadata, delivery tracking
  • call_logs — voice transcripts, embeddings, VAPI IDs
  • kb_documents, kb_chunks — vector search
  • prompt_templates, ai_model_configs, ai_usage_log
  • campaigns, campaign_enrollments
  • quotes, bookings — full rental lifecycle
  • invoices — QB sync, dunning steps
  • driver_assignments, driver_status_updates
  • review_requests
  • kpi_targets, kpi_snapshots
  • suppression_list, audit_log
  • webhook_subscriptions, webhook_deliveries
5. AI Layer — OpenRouter

Single LLM gateway with per-task model selection, fallback chains, daily cost caps, and usage logging. Model swaps require only a DB row change — no redeploy.

Task → model examples: outreach & replies → Claude Sonnet; classification → Gemini Flash; collections → Haiku.

6. AI Voice Agent (VAPI)
  • Business-hours → human; after-hours & overflow → AI
  • Functions: check_availability, quote_price, create_lead, book_job, escalate_to_human
  • Post-call: transcript → conversation inbox → lead/booking creation
  • Recording stored in Supabase Storage
7. QuickBooks Integration
  • OAuth 2.0 connection
  • Auto-invoice when booking marked complete
  • Bidirectional customer sync
  • Overdue detection → AI dunning sequence (friendly → firm → final)
  • DSO tracking dashboard
8. Driver Communication Hub
  • Mobile-responsive web view (no separate app)
  • Automated AM dispatch SMS at configurable time
  • Inbound SMS: "delivered" → booking status update
  • Strict separation of driver vs. lead SMS traffic
9–11. Lead Acquisition, Inbox, Knowledge Base

Acquisition: Multi-source import, fuzzy dedup, four segments, permit records (Harris, Fort Bend), enrichment.

Inbox: Unified threads, AI-suggested replies, human review queue, escalation triggers (pricing disputes, complaints).

KB: Versioned markdown, per-segment overrides, pgvector retrieval, auto-suggestions from repeated questions.

12. Pipeline, Bookings & Dispatch

Kanban: New → Contacted → Replied → Qualified → Quoted → Booked → Delivered → Completed → Lost

Calendar view, driver assignment, realtime updates (Supabase Realtime), per-stage SLA alerts.

Booking confirmation: email + SMS on create; ETA SMS when driver marks en route.

13–14. Reviews & Accounts

Reviews: Post-job SMS sentiment check → positive gets Google link, negative gets private feedback form.

Accounts: Auto-link returning customers by phone/email, lifetime value, health view, tiered contractor pricing.

15–16. Analytics & Background Jobs

Dashboard: Today view, six KPI cards, funnel per segment, AI cost per job, SLA breach alerts, weekly owner email.

Jobs: Follow-up scheduler (hourly), lead scoring (nightly), overdue invoices (daily), AM dispatch (cron), embedding refresh, webhook retries.

17–18. Frontend & API Endpoints

Key routes:

  • /api/leads, /api/accounts, /api/conversations/[id]/send|suggest
  • /api/kb/search, /api/ai/test, /api/quotes, /api/bookings
  • /api/driver/today, /api/analytics/today|kpis
  • Webhooks: SendGrid, Twilio, VAPI, Stripe, QuickBooks

UI pages: Today, Inbox, Leads, Pipeline, Dispatch, Bookings, Accounts, KB, Campaigns, Analytics, Settings.

19–20. Security, Compliance & Webhooks
  • Supabase Auth (magic link + Google OAuth), RLS, role-based access
  • CAN-SPAM, TCPA, voice recording consent
  • Webhook signature verification for all inbound providers
  • Public webhook subscriptions for Zapier — 15+ event types, HMAC signing, retry with backoff
21. Phased Build Plan (10 phases · 20 weeks)
  • Phase 1 (Wk 1–2): Foundation — schema, auth, lead CRUD, CSV import, dashboard shell
  • Phase 2 (Wk 3–4): AI core — OpenRouter, prompts, KB, outreach, cost logging
  • Phase 3 (Wk 5–6): Conversations — SendGrid, Twilio, inbox, Gmail drafts
  • Phase 4 (Wk 7–8): Voice — VAPI, routing, transcripts
  • Phase 5 (Wk 9–10): Automation — campaigns, kanban, lead scoring
  • Phase 6 (Wk 11–12): Bookings — quotes, Stripe, dispatch, driver SMS
  • Phase 7 (Wk 13–14): QuickBooks — auto-invoice, dunning, DSO
  • Phase 8 (Wk 15–16): Reviews & accounts
  • Phase 9 (Wk 17–18): Analytics polish, A/B testing, audit log
  • Phase 10 (Wk 19–20): Ecosystem — Zapier app, permit scrapers, API docs

Path B pilot = Phases 1–3 only.

22. Cost Model & Success Definition

Monthly operating (single org): ~$270–$940/mo (Supabase, Vercel, OpenRouter, VAPI, Twilio, SendGrid, Stripe, Apollo, Sentry, PostHog).

ROI: ~1–3 rentals/mo covers the stack; ~20 hrs/week saved ≈ $8K/mo value.

6-month success targets:

  • 80%+ inbound calls handled without human
  • 15+ admin hours saved per week
  • Lead response under 5 minutes
  • 25%+ conversion lift
  • DSO −10 days
  • 3× Google review velocity
