3. Path A — detailed vendor spec

Scope: Configure and integrate; no custom application code.

  • iCans Plus (~$159/mo): CRM, online booking, dispatch, driver app, QB sync, customer records, job pipeline
  • VAPI: After-hours voice — generic dumpster rental script; bookings land in iCans manually or via webhook if available
  • Zapier Pro: New lead → Claude draft email; missed call → SMS; job complete → NiceJob review request
  • Claude API (via Zapier): Basic email drafts — no owner's-voice training, no RAG
  • NiceJob (~$75/mo): Post-job review SMS + Google link
  • Twilio + SendGrid: Messaging pipes (often bundled through iCans or Zapier)
  • Apollo Basic (~$50/mo): Contractor lead lists → CSV → iCans import
  • QuickBooks Plus: Invoicing (existing workflow)

Limitations: Fragmented inbox across Gmail/iCans; generic AI quality; Zapier brittleness at scale; no unified lead scoring or custom KPI dashboard.

Build: ~25 hrs · Deliverable: configured vendor stack + documentation

4. Path B — detailed hybrid spec ★

Scope: Custom AI application + iCans for everything operational post-quote.

We build (custom layer)

  • Foundation: Supabase schema (leads, conversations, messages, KB, campaigns, AI config), Next.js auth, lead CRUD, CSV import
  • AI core: OpenRouter router, prompt templates, cost logging, KB editor + pgvector embeddings
  • Conversations: SendGrid inbound/outbound, Twilio SMS (lead vs driver routing), unified inbox UI, AI suggestions, Gmail owner's-voice drafts
  • v1.1 add-ons: VAPI voice → transcript → inbox; full campaign builder; pipeline kanban for pre-booking leads
  • v1.2 add-ons: Google review SMS flow; KPI dashboard; AI dunning email drafts for overdue QB invoices

iCans handles (not rebuilt)

  • Dispatch board, route optimization, driver mobile app
  • Quote templates, booking calendar, job lifecycle post-booking
  • QuickBooks customer + invoice sync
  • Online booking form (webhook → custom lead ingest optional)

Integration point: Lead qualified in custom CRM → manual or webhook handoff to iCans booking. Booked job status can sync back for inbox context.

Pilot (Phases 1–3): 40–50 hrs · $6K–$7.5K · 6 weeks · Full Path B: ~70 hrs · $10.5K

5. Path C — detailed full-custom spec

Scope: Complete system — all 16 feature modules, 25 database tables, 25+ API routes. No iCans dependency.

  • Lead acquisition: CSV, Apollo, Clay, permit records, webhooks, duplicate detection, scoring 0–100
  • AI outreach: Per-segment prompts, owner's-voice, A/B variants, email/SMS/LinkedIn
  • Voice agent: VAPI with check_availability, quote_price, create_lead, book_job, escalate_to_human
  • Reply handler: Multi-channel inbound, RAG, confidence scoring, escalation triggers
  • Follow-up scheduler: Per-segment cadence (residential 3-5-7-14; commercial 7-14-30), re-engagement
  • Quotes & booking: Dynamic pricing, PDF, e-sign, Stripe, ETA SMS on en route
  • QuickBooks: OAuth, auto-invoice on complete, bidirectional sync, AI dunning, DSO dashboard
  • Driver hub: Mobile web view, AM dispatch SMS, inbound status parsing ("delivered" → status update)
  • Pipeline & dispatch: Kanban (New → Lost), calendar, driver assignment, Supabase Realtime, SLA alerts
  • Reviews & accounts: Post-job sentiment SMS; LTV, tiered contractor pricing
  • Analytics: Today dashboard, six KPI cards, funnel, AI cost per job, weekly owner email
  • Ecosystem (Phase 10): Public webhooks, Zapier app, permit scrapers, API docs

Build: ~135 hrs · 20 weeks · 10 phases · Deliverable: fully owned production application

6. Database & data model
Path A

Data lives in iCans, QuickBooks, Apollo, and Gmail. No shared custom schema. Reporting requires exporting from each vendor.

Path B

Custom Supabase (~12 core tables): organizations, org_members, leads, conversations, messages, kb_documents, kb_chunks, prompt_templates, ai_model_configs, ai_usage_log, campaigns, campaign_enrollments, tags, suppression_list. Bookings/invoices remain in iCans/QB.

Path C

Full schema (25 tables): All Path B tables plus accounts, call_logs, quotes, bookings, invoices, driver_assignments, driver_status_updates, review_requests, kpi_targets, kpi_snapshots, audit_log, webhook_subscriptions, webhook_deliveries. Row-level security on every tenant table.
